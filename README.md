# +Foco — Plataforma de Apoio ao Estudante e Gestão de Estudos

> Plataforma web desenvolvida para auxiliar estudantes na organização da rotina acadêmica, centralizando ferramentas essenciais para aumentar o foco, produtividade e gerenciamento do tempo.

---

## Sobre o Projeto

O **+Foco** é uma aplicação web criada como parte da disciplina de **Desenvolvimento Front-end para Web**. O objetivo principal do projeto é solucionar os desafios comuns enfrentados por estudantes, como desorganização, atrasos nas entregas e falta de foco durante as sessões de estudo.

### Funcionalidades Principais
- **Calendário Acadêmico:** Acompanhamento visual de datas importantes, prazos e exames.
- **Timer Pomodoro:** Gerenciamento de ciclos de estudo focado e pausas estratégicas para evitar a fadiga mental.
- **Cronograma & Gestão de Atividades:** Organização das matérias, tarefas e prioridades em um único painel.
- **Cadastro Acessível de Atividades:** Formulário completo e adaptado para inclusão de novas tarefas com controle de prazos e alertas.
